DAPUR SENJA — a fast warung cooking game: take ingredients, chop them on the timed green-zone meter, cook them on two stove burners, assemble the dish on the plate and serve it at the window before the customer's patience runs out. Four original recipes, a combo multiplier for quick serves, and a Senja Rush in the last 45 seconds when orders come faster and patience runs shorter.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, static files only. WASD / arrows to walk, E to use a station, click a station to walk to it, P to pause, M to mute.
